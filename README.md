# Healing Tree 🌳

[![Flutter](https://img.shields.io/badge/Flutter-3.x-02569B?logo=flutter)](https://flutter.dev)
[![Dart](https://img.shields.io/badge/Dart-3.x-0175C2?logo=dart)](https://dart.dev)

**Healing Tree**는 AI 기반 감성 케어 일기 앱입니다. 일상을 기록하고, AI의 따뜻한 피드백을 통해 감정을 돌보세요.

## 📖 프로젝트 소개

Healing Tree는 단순한 일기 앱을 넘어, 사용자의 감정을 이해하고 맞춤형 피드백을 제공하는 감성 케어 플랫폼입니다.

### 주요 기능

- 📝 **일기 작성**: 텍스트, 사진, 음성으로 일상 기록
- 🤖 **AI 피드백**: 감정 분석 및 맞춤형 조언 제공
- 📊 **감정 트래킹**: 시간에 따른 감정 변화 시각화
- 🎨 **개인화**: 다양한 테마 및 맞춤 설정
- 🔒 **프라이버시**: 철저한 데이터 보호 및 암호화

## 🛠 기술 스택

- **Framework**: Flutter 3.x
- **언어**: Dart
- **상태 관리**: Riverpod
- **로컬 DB**: Hive
- **AI**: OpenAI GPT-4 API
- **Backend**: Firebase

## 🚀 시작하기

### 필수 요구사항

- Flutter SDK 3.x 이상
- Dart 3.x 이상
- Android Studio / Xcode
- Firebase 계정
- OpenAI API 키

### 설치 및 실행

```bash
# 저장소 클론
git clone https://github.com/yourusername/Healing-Tree.git
cd Healing-Tree

# 의존성 설치
flutter pub get

# 앱 실행
flutter run
```

### 환경 설정

1. Firebase 프로젝트 생성 및 설정
2. OpenAI API 키 발급
3. `.env` 파일 생성 및 API 키 설정

```env
OPENAI_API_KEY=your_api_key_here
```
